# 平板快捷输入示例

四个按钮依次为长文本总结、图片分析、代码生成和简单问答。点击按钮会新建独立会话、填入提示词，并由用户编辑后手动发送。图片分析同时附带内置猫图。

- 长文本总结包含2022个汉字的虚构社区图书共享项目复盘，要求生成300～500字总结。
- 图片分析使用 `cat.jpg`，要求描述可见外观、姿态和环境，不推测无法确认的信息。
- 代码生成要求输出一个完整的 HTML/CSS/JavaScript 待办事项项目。
- 简单问答要求用100～200字介绍华为公司。

`manifest.json` 记录素材和输出要求。猫图由内置 image_gen 生成，再压缩为820×820的JPEG，共717025字节（约700 KiB）。应用中的同名资源位于 `apps/agent-client/entry/src/main/resources/rawfile/quick-inputs/`；实际发送仍使用现有近场图片编码和大小限制。

提示词编入 `TabletQuickInputs.ets`，并由回归测试核对它与这四份文本文件一致。设置页支持编辑四个提示词，留空可停用对应按钮。升级时旧版默认示例自动替换为新示例，自定义文字和停用状态保留。
